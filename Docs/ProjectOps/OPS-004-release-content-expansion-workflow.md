# 출시형 콘텐츠 확장 작업 흐름

> 출시 기준 콘텐츠 확장 논의를 위한 단계 고정 문서. 세부 자산/챕터/스테이지 결정은 각 단계 진입 후 별도 문서에서 다룬다.

## 1. 목적
- 출시형 게임 기준으로 비주얼/콘텐츠 분량을 확장할 때, 세션마다 작업 순서가 흔들리지 않도록 상위 흐름을 고정한다.
- 사람과 agent가 함께 논의할 때 "지금 어느 단계에 있는가"를 빠르게 합의할 수 있게 한다.
- 현재 문서는 단계와 종료 조건만 고정하며, 챕터 수, 스테이지 목록, 자산 수량 같은 상세 결정은 각 단계 문서에서 분리해 다룬다.

## 2. 전제
- 메인 비주얼 방향은 컨셉 아트 기반 `cozy fantasy + magical cleanup` 축으로 확정된 상태를 전제로 한다.
- 본 문서는 포트폴리오/데모 분량이 아니라 실제 출시형 게임 기준의 콘텐츠 확장 흐름을 다룬다.
- 구현 착수 전까지는 단계별 논의 문서와 작업 보드를 통해 상세안을 축적하되, 상위 흐름 자체는 본 문서를 기준으로 유지한다.

## 3. 고정 작업 흐름
### 3.1 1단계 — 챕터 구조
목표:
- 게임 전체를 어떤 챕터들로 나눌지 정한다.
- 각 챕터의 공간 테마, 감정, 난이도 역할을 정한다.

이 단계에서 다룰 것:
- 챕터 수
- 챕터별 공간/오브젝트 테마
- 챕터 간 비주얼 변주 범위
- 각 챕터의 핵심 위험 축과 플레이 감정

종료 조건:
- "이 게임은 어떤 챕터들로 구성되는가"를 한 페이지 수준으로 설명할 수 있다.

### 3.2 2단계 — 스테이지 분량
목표:
- 챕터별 스테이지 수와 전체 캠페인 분량을 정한다.
- 각 스테이지가 캠페인 안에서 어떤 역할을 맡는지 정한다.

이 단계에서 다룰 것:
- 챕터당 스테이지 수
- 튜토리얼 / 소개 / 응용 / 압박 / 종합 / 후반부 역할 배치
- 전체 캠페인 길이와 분량 감각
- 스테이지 간 난이도 곡선

종료 조건:
- 전체 스테이지 목록과 각 스테이지 역할이 표 형태로 정리된다.

### 3.3 3단계 — HazardActor 라이브러리
목표:
- 각 챕터에서 반복적으로 사용할 위험 개체 풀을 정한다.
- 위험을 추상 패턴이 아니라 "문제 오브젝트" 단위로 정리한다.

이 단계에서 다룰 것:
- actor 종류 수
- actor별 소속 챕터
- actor별 전조 문법
- 기본 행동 / 강화 행동
- 재사용 actor와 챕터 전용 actor 구분

종료 조건:
- 스테이지 배치 논의에 사용할 actor 후보 풀이 충분히 확보된다.

### 3.4 4단계 — 자산 생산 범위
목표:
- 출시 분량 기준으로 실제 필요한 아트/VFX/SFX 생산 범위를 계산한다.
- 필수 생산분과 후순위 장식분을 구분한다.

이 단계에서 다룰 것:
- 챕터별 환경 자산 세트
- actor 외형 자산 세트
- UI / HUD / 월드 인디케이터 추가 자산
- VFX / SFX / BGM 최소 세트
- 재사용 비율과 신규 제작 비율

종료 조건:
- 제작해야 할 자산 목록과 우선순위가 잡힌다.

### 3.5 5단계 — 제작 착수
목표:
- 앞 단계에서 정한 구조를 실제 제작 순서로 내린다.
- 첫 vertical slice 챕터와 검증 기준을 고정한다.

이 단계에서 다룰 것:
- 첫 제작 챕터
- 첫 제작 범위의 검증 기준
- 샘플 스테이지 세트 범위
- 이후 양산 순서와 handoff 기준

종료 조건:
- 실제 작업 가능한 backlog와 단계별 생산 순서가 준비된다.

## 4. 단계 운영 원칙
### 4.1 현재 단계 우선
- 항상 현재 단계의 미결정 항목을 먼저 닫는다.
- 다음 단계 논의는 참고 수준으로만 허용하고, 상세 결정은 선행 단계 종료 후에 확정한다.

### 4.2 문서는 단계 진입 후 필요 최소한만 생성
- 본 문서 외의 상세 문서는 단계 진입 시점에 필요한 만큼만 만든다.
- 문서 종류를 미리 과도하게 확정하지 않는다.
- 각 단계 문서는 해당 단계의 결정, 오픈 이슈, 종료 조건 충족 여부를 설명할 수 있으면 충분하다.

### 4.3 논의와 제작을 분리
- 1~4단계는 구조와 범위를 고정하는 논의 단계다.
- 실제 대량 자산 생산과 구현 착수는 5단계에서 시작한다.
- 단, 검증용 소규모 샘플 제작은 논의 보조 수단으로 허용한다.

### 4.4 세션 간 연속성 유지
- 이후 세션에서는 먼저 현재 단계와 종료 조건 충족 여부를 확인한다.
- 세부 의사결정이 쌓여도, 상위 흐름 변경이 필요하지 않으면 본 문서는 수정하지 않는다.
- 상위 흐름 자체를 바꿔야 할 때만 본 문서를 갱신한다.

## 5. 현재 상태
- 메인 비주얼 방향 확정: 완료
- 현재 진입 대상 단계: `1단계 — 챕터 구조`
- 아직 확정하지 않은 범위:
  - 챕터 수와 챕터별 테마
  - 챕터별 스테이지 수와 역할
  - HazardActor 라이브러리 규모
  - 출시 분량 기준 자산 생산 범위

## 6. 사용 규칙
- 사람/agent와의 후속 논의는 먼저 본 문서의 현재 단계부터 확인한다.
- 새로운 상세 문서를 만들 때는, 본 문서의 어느 단계에 속하는지 문서 서두나 metadata 인접 위치에서 드러내는 것을 권장한다.
- 단계 종료 조건을 만족하지 못한 상태에서 다음 단계 세부안으로 확정하는 경우, 그 이유와 임시성을 함께 남긴다.
