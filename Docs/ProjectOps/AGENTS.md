# AGENTS.md (Docs/ProjectOps)

## Document Role
- Documents in this folder describe **project management plans and operating assumptions**.
- They are **NOT decisions** and **NOT binding architecture rules**.

## Usage Rules
- Use these documents to align priorities, scope, and execution order.
- Do NOT treat contents as finalized architecture or implementation details.
- ADR is for important decisions and rationale, not every project update.
- Create ADRs for high-impact technical choices with long-term maintenance or coordination cost.
- Keep formatting constraints minimal.
- Mandatory: file name format and `## Metadata`.
- Suggested (session-level): section order, heading style, and template structure.

## Editing Rules
- Updating these documents does NOT imply a technical decision.
- If implementation diverges, update this document first.
- Add or update an ADR only when the divergence includes an important decision worth traceability.
