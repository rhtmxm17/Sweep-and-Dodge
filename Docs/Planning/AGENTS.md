# AGENTS.md (Docs/Planning)

## Document Role
- Documents in this folder describe **design intent, assumptions, and plans**.
- They are **NOT decisions** and **NOT binding rules**.

## Usage Rules
- Use these documents as reference when designing systems.
- Do NOT treat contents as finalized behavior.
- Any confirmed decision must be recorded in an ADR.

## Editing Rules
- Updating these documents does NOT imply a design decision.
- If implementation diverges or a choice is finalized, create or update an ADR instead.
