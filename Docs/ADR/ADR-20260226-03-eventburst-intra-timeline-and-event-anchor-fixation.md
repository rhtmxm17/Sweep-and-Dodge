# ADR-20260226-03-eventburst-intra-timeline-and-event-anchor-fixation
> 지속 사건형 스폰을 Emission 책임으로 확장하고, 이벤트 단위 기준점 고정 규약을 채택한 결정

## 상태
- 합의됨 (문서 반영, 구현 예정)

## 배경
- `DirectionMode.Spiral`은 각도 변화 표현에는 적합하지만, "한 이벤트 내부에서 시간 간격을 두고 연속 발사"라는 의도를 직접 표현하지 못한다.
- 사용자 의도는 "샘플링으로 확정된 기준점에서 이벤트 타임라인 동안 연속 발사"이며, 이는 방향이 아니라 방출 리듬(Emission) 책임에 가깝다.
- 기준점 재샘플링 시점이 모호하면 이벤트 중 위치 점프가 발생해 체감 일관성과 디버깅 가능성이 낮아진다.

## 결정
1. 책임 경계
- 이벤트 내부 타임라인(지속 발사 간격/회수)은 `Emission` 책임으로 둔다.
- `Direction`은 각 샷의 각도 규약만 담당한다.

2. 사건형 이벤트 모드 확장(권장 방안)
- `EventShotSchedule`: `Instant` / `Timed`
  - `Instant`: 기존과 동일하게 이벤트 1회에서 샷을 즉시 소비한다.
  - `Timed`: 이벤트 1회 내부에서 샷을 시간 간격으로 분할 소비한다.
- `EventShotIntervalSec`:
  - `Timed`에서 필수, `> 0`.
- `BurstShotsPerEvent`:
  - 이벤트 1회 내부 샷 횟수로 유지한다.
  - `Timed`에서는 "샷 사이클 수"로 해석한다.
- 적용 모드:
  - `Poisson`, `EventBurst` 모두에 동일하게 적용한다.
  - `Poisson`은 이벤트 발생 시점(확률 과정)만 다르고, 발생 확정 이후의 샷 소비 규약은 동일하다.

3. 이벤트 기준점 고정(Event Anchor Fixation)
- 샘플링 기준점은 이벤트 시작 시 1회 확정하고, 이벤트 종료까지 고정한다.
- 고정 좌표는 월드 기준으로 유지하며, 이벤트 진행 중 Source/Player 이동에 따라 재계산하지 않는다.
- 고정은 이벤트 범위에만 적용한다. 다음 이벤트는 다시 샘플링한다.

4. 샘플링 실패 정책 일관성
- `PlayerNoSpawnRadius` 등으로 기준점 추출이 실패한 경우의 처리 정책은 기존 Sampling 실패 정책을 그대로 사용한다.
- 이 정책은 스폰 형태(`NWay`, `Spiral`, 지속 사건형 등)와 무관하게 동일하게 유지한다.

## 대안
- Spiral/Payload 확장으로 지속 사건형 구현
  - 장점: 단기 구현이 단순해 보일 수 있음
  - 단점: Direction/Payload 책임 과부하, Emission과 중복 규칙 증가, 유지보수성 저하
- 이벤트 내부에서 매 샷 재샘플링
  - 장점: 동적 위치 반영
  - 단점: 의도 대비 위치 흔들림 증가, 재현성 저하, 디버깅 난이도 증가

### GameObject/OOP 중심 설계 관점 (스터디 메모)
- GameObject/OOP 중심이었다면 `Payload`가 하위 Emission(또는 Sub-Emitter)을 발행하는 직관적 설계를 대안으로 채택할 가능성이 높다.
- 근거:
  - 프리팹/컴포넌트 단위로 "탄이 또 다른 발사를 유발"하는 계층 표현이 직관적이다.
  - 코루틴/타이머 기반으로 하위 발사 타임라인을 각 오브젝트에 국소화하기 쉽다.
- 본 프로젝트(DOTS/ECS)에서는 채택하지 않음:
  - 발행 책임이 Payload 쪽으로 분산되면 요청 집계/예산/원자성 계약이 약해질 수 있다.
  - Emission 단일 책임 경계를 유지하는 쪽이 소유권/검증/성능 추적에 유리하다.

## 결과
- "한 이벤트 내부 타임라인" 요구를 Emission 계약으로 명시해 모델 경계가 명확해진다.
- LineEven/PointSet/UniformField 계열 모두에서 이벤트 단위 기준점 고정 규약을 공통 적용할 수 있다.
- `Poisson`/`EventBurst` 모두에서 동일한 이벤트 내부 샷 스케줄 규약을 재사용할 수 있다.
- Direction은 각도 표현에 집중하고, 지속 사건형은 Emission 확장으로 일관되게 확장할 수 있다.
