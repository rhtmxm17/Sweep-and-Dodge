> 프로젝트에 추가된 컨셉 이미지를 기준으로, 아이디어 제안과 비주얼 톤 정렬에 사용할 키워드 보드를 정의한다. 구현 스펙이나 기술 판단의 근거가 아니라, 색감/분위기/어휘/제안 방향의 공통 참조점으로 다룬다.

## 1. 목적
- 프로젝트에 추가된 비주얼 레퍼런스를 게임 제안용 키워드와 방향성으로 환원한다.
- 색감, 분위기, 플레이어 판타지, UI/VFX 언어를 빠르게 맞추기 위한 공용 어휘를 만든다.
- "무엇을 이 레퍼런스로 결정할 수 있고, 무엇은 결정할 수 없는가"를 분리해 오해를 줄인다.
- 후속 아트 레퍼런스가 추가될 때 같은 방식으로 정리할 수 있는 최소 템플릿을 남긴다.

## 2. 적용 범위
- 분위기 키워드 추출
- 색감/조명 방향 제안
- 플레이어 판타지와 세계관 어휘 제안
- UI, VFX, 카피라이팅, 연출 아이디어의 초기 제안 기준
- 후속 레퍼런스 정리 시 재사용 가능한 문서 구조

## 3. 비범위
- 전투 가독성 기준 확정
- 최종 캐릭터 원화, 배경 원화, UI 시안 확정
- 카메라 구도, 화면 밀도, 타일/오브젝트 배치 규칙 확정
- DOTS 구조, 소유권, 업데이트 순서, 데이터 계약 등 기술 판단
- 특정 에셋 제작 지시서나 생산 파이프라인 규격

## 4. 가정/제약
- 본 문서는 "이 이미지의 감정과 어휘를 게임 제안에 어떻게 번역할까"를 다루며, 그대로 재현할 최종 비주얼 타깃을 의미하지 않는다.
- 레퍼런스 이미지는 `Docs/Art` 아래에 저장된 프로젝트 자산으로 관리한다.
- 레퍼런스 이미지의 디테일보다, 반복 활용 가능한 키워드와 판타지 축을 우선 추출한다.
- 기술/UI/레벨 설계는 별도 문서와 검증 기준을 따른다.

## 5. 레퍼런스 요약
### 5.0 참조 파일
- asset: [../Art/concept-magical-cleanup-witch-workshop-v01.png](../Art/concept-magical-cleanup-witch-workshop-v01.png)
- note: 현재 톤 키워드 보드는 위 이미지를 1차 기준 레퍼런스로 사용한다.

### 5.1 관찰 포인트
- 어린 마녀가 난장판이 된 연금술 작업실을 빗자루로 정리하는 장면
- 따뜻한 호박색 조명과 보라색 포인트 의상이 함께 쓰인 색 배치
- 먼지, 반짝이, 병 파편, 메모지, 약병이 어수선하지만 유쾌한 분위기를 만든다
- "전투"보다 "정리, 수습, 수거, 정돈"의 행위가 중심으로 보인다
- 판타지 소품과 기계적 장비가 함께 있어 `domestic magic + gadget` 축이 느껴진다

### 5.2 레퍼런스 상태
- status: `idea reference`
- use_for: 분위기, 키워드, 비주얼 언어, 카피 방향
- not_for: 구현 스펙, 난이도 판정, 최종 화면 밀도 확정

## 6. 추출 키워드
### 6.1 핵심 톤 키워드
- `cozy fantasy`
- `magical cleanup`
- `whimsical witch`
- `alchemy workshop`
- `warm amber lighting`
- `purple accent`
- `sparkling dust`
- `mess-to-order transformation`
- `cute but industrious`
- `domestic magic with machinery`

### 6.2 보조 키워드
- `lived-in clutter`
- `soft storybook rendering`
- `bright charm over menace`
- `contained chaos`
- `cleanup as craft`
- `small heroine, oversized task`

## 7. 게임 해석 제안
### 7.1 플레이어 판타지
- 플레이어는 단순 생존자가 아니라 "어질러진 마력을 정리하는 현장형 마녀"로 읽히는 편이 어울린다.
- 회피와 수집은 "위험을 피한다"보다 "흩어진 것을 수습하고 정돈한다"는 태도로 번역할 수 있다.
- 빗자루, 가방, 정제 도구 같은 소품은 이동/청소/수거를 하나의 판타지로 묶는 핵심 이미지가 될 수 있다.

### 7.2 탄막/오브젝트 해석
- 탄막은 순수한 적대 투사체 외에도 `찌꺼기`, `잔재`, `흩어진 마력 파편`으로 해석 가능하다.
- 수집물은 `에센스`, `반짝 가루`, `정화 가능한 조각`, `회수 대상 시약` 같은 어휘가 어울린다.
- 청소/정리 행동 성공 시 "더 깨끗해졌다"는 감각이 즉시 보이는 방향이 좋다.

### 7.3 월드/연출 톤
- 위협 일변도보다 "정리하면 숨통이 트이는 공간"의 감정을 우선한다.
- 배경은 지나치게 비어 있기보다, 적당히 어수선한 작업실/실험실/수습 현장 쪽이 키워드와 잘 맞는다.
- 캐릭터 반응 문구는 냉정한 시스템 메시지보다 생활감 있는 짧은 반응이 적합하다.

## 8. 색감 및 표현 방향
### 8.1 기본 팔레트 축
- 주조색: 따뜻한 `amber`, `honey gold`, `soft brown`
- 보조색: `violet`, `deep purple`, `muted indigo`
- 포인트색: `spark gold`, `teal glass`, `potion green`

### 8.2 표현 원칙
- 배경 전체를 차갑고 어둡게 누르기보다, 따뜻한 빛 안에서 위험과 난장판이 공존하도록 잡는다.
- 포인트색은 전역 남용보다 플레이어 장비, 상호작용 가능 요소, 중요한 효과에 제한적으로 넣는다.
- 반짝임은 보상과 정리 성공감에 연결하고, 경고는 채도보다 움직임/형태로 우선 구분한다.

## 9. UI / VFX / 카피 적용 힌트
### 9.1 UI
- 하드 SF 패널보다 메모지, 장부, 작업실 태그, 시약 라벨 같은 어휘가 더 어울린다.
- HUD 카피는 "경고"만이 아니라 "정리 상태", "수습 진척", "정화 가능성" 같은 단어로 확장할 수 있다.
- 지나치게 장식적인 프레임을 늘리기보다는, 따뜻한 표면감과 작은 포인트 장식 정도로 제한한다.

### 9.2 VFX
- 레이저/전기 느낌보다 `dust`, `spark`, `trail`, `powder`, `swirl` 계열이 키워드와 잘 맞는다.
- 청소 성공 피드백은 사라짐보다 "먼지가 걷히고 빛나는 흔적이 남는" 방향이 적합하다.
- 수집 피드백은 자석처럼 빨려드는 느낌보다 "반짝 가루가 정리되어 담긴다"는 감각이 좋다.

### 9.3 카피/대사
- `정리됐다`, `가라앉혔다`, `주워 담았다`, `정제했다`, `쓸어 모았다`
- `난장판`, `잔재`, `찌꺼기`, `파편`, `흔적`, `먼지`
- `위협 제거`보다 `수습`, `정리`, `정돈`, `정화` 쪽이 이 레퍼런스와 더 가깝다

## 10. 사용 규칙
### 10.1 이 문서로 결정 가능한 것
- 제안 단계에서 사용할 톤 키워드
- 색감/분위기 레퍼런스
- 플레이어 판타지 표현 문장
- UI/VFX/카피 방향의 예시 어휘

### 10.2 이 문서로 결정하면 안 되는 것
- 최종 아트 스타일 확정
- 실제 전투 시인성 기준
- 화면 정보량 한계
- 구현 우선순위와 기술 구조

## 12. 현재 기준안
- 현재 공유 이미지는 `cozy fantasy`와 `magical cleanup` 축을 잡는 데 유효한 레퍼런스로 본다.
- 플레이어 판타지는 "싸우는 마녀"보다 "수습하고 정리하는 마녀" 쪽으로 제안하는 편이 현재 게임 컨셉과 잘 맞는다.
- 비주얼 제안 시 따뜻한 조명, 보라 포인트, 반짝 먼지, 작업실/연금술 어휘를 우선 키워드로 사용한다.
- 기술 설계와 최종 시각 자산 확정은 본 문서로 대체하지 않는다.

## 13. 오픈 이슈
- 이 방향을 실제 게임의 메인 테마로 밀지, 특정 챕터/바이옴의 한정 톤으로 둘지 정리가 필요하다.
- "청소"와 "탄막 회피" 중 어느 축을 주 플레이 감정으로 전면에 둘지 후속 논의가 필요하다.
- 후속 레퍼런스를 `Docs/Art` 하위에서 어떤 네이밍/분류 규칙으로 누적할지 운영 방침이 필요하다.
