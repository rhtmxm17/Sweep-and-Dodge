# AGENTS.md (Docs/GameDesign)

## Document Role
- Documents in this folder describe **game design intent, assumptions, and plans**.
- They are **NOT decisions** and **NOT binding rules**.

## Usage Rules
- Use these documents as reference when designing gameplay systems.
- Do NOT treat contents as finalized behavior.
- ADR is for important decisions and rationale, not every design change.
- Create ADRs when a decision has high rollback cost, cross-system impact, or needs explicit trade-off evidence.
- Keep formatting constraints minimal.
- Mandatory: file name format and `## Metadata`.
- Suggested (session-level): section order, heading style, and template structure.

## Editing Rules
- Updating these documents does NOT imply a design decision.
- If implementation diverges, update this document first.
- Add or update an ADR only when the divergence introduces an important decision worth long-term traceability.
