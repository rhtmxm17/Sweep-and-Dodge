# 05_Content
> GitHub 공개 저장소에서 제외하는 콘텐츠 자산 보관 경로

## 용도
이 디렉토리는 프로젝트에서 사용하지만 GitHub 공개 저장소에는 포함하지 않는 콘텐츠 자산을 보관한다.
공개 저장소는 코드, 구조, 작업 방식을 공유하는 것을 목적으로 하므로 이 경로의 원본 자산은 커밋하지 않는다.

## 범위
이 문서에서 `재배포 불가능`은 이미지, 오디오, VFX 등의 원본 자산을 GitHub 공개 저장소를 통해 공개하거나 배포할 수 없다는 의미다.
해당 자산이 Unity 빌드 결과물에 런타임 콘텐츠로 포함되는 것은 이 제한의 대상이 아니다.
단, 개별 자산에 별도 라이선스 조건이 있다면 해당 조건을 우선한다.

별도 명시가 없는 한 이 경로의 하위 원본 자산은 모두 GitHub 공개 저장소 제외 대상으로 간주한다.

## 폴더 규칙
콘텐츠는 도메인 기준으로 나누고, 그 아래에서 타입별로 정리한다.

예시:
```text
Assets/_Project/05_Content/
  UI/
    Images/
    Audio/
    VFX/
  Player/
    Images/
    Audio/
    VFX/
  Bullets/
    Images/
    Audio/
    VFX/
  Environment/
    Images/
    Audio/
    VFX/
  Shared/
    Images/
    Audio/
    VFX/
  90_Temp/
```

## 운영 규칙
- 공용 자산만 `Shared/`에 둔다.
- 임시 작업물은 `90_Temp/`를 사용하고 주기적으로 정리한다.
- 공개용 대체 자산이나 placeholder가 필요하면 이 경로 밖에 둔다.
- 빌드에 필요한 자산은 로컬 또는 별도의 비공개 배포 경로를 통해 복원한 뒤 빌드한다.

## 참고
GitHub 공개 저장소를 체크아웃한 개발 환경에서 이 경로의 원본 자산이 누락되는 것은 정상이다.
이는 완성된 빌드 결과물에서 해당 콘텐츠를 제외해야 한다는 의미가 아니다.
